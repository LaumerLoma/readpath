# 3 · Experiments

Numerical checks of [1 · Theory](../1-theory/) and [2 · Game theory](../2-game-theory/). Each
experiment has its own folder with a README, its figure, and a `results.json` with every number
behind the figure. Everything here is regenerated by one command; nothing is edited by hand
except the READMEs.

| | Experiment | Tests | Method | Statistics | Result |
|---|---|---|---|---|---|
| [E1](01-timing/) | Timing | Proposition 1 | Simulated padded fabricator vs honest latencies, two-sample KS distance | 6 seeds × 20,000 samples per side; mean ± 95% CI; KS critical value | Matches $F_R(\ell_G)$ within 0.010 (critical value 0.014) |
| [E2](02-checking/) | Checking | Proposition 2 | Best-of-$n$ pass rate over a grid of latency × quality gap | 300 samples per cell; max standard error 0.029 | 24 retries match the honest pass rate at equal quality |
| [E3](03-corroboration/) | Corroboration | Proposition 4 | Closed form | Deterministic | On rare questions, 3 agreeing sources drop the posterior from 0.64 to 0.07 |
| [E4](04-anchors/) | Anchors | Proposition 5 | Closed form | Deterministic | Pre-committed traffic share rises from 0.29 to 0.90 by generation 12 (Zipf 0.9) |
| [E5](05-network/) | Network | Proposition 3, dynamics | Agent-based simulation, 300 agents, 13 generations, 8 [treatments](05-network/treatments/) | 6 seeds per treatment; mean ± 95% CI (Student's t) | Every treatment except the control drops below advantage 0.5 within 10 generations |

## Statistical protocol

- **Seeds.** Every stochastic experiment runs with seeds $0, \dots, 5$. Each seed is a full,
  independent run. Seeds are fixed, so every number reproduces exactly.
- **Intervals.** "Mean ± CI" is the mean over seeds with a 95% confidence interval from Student's
  $t$ with $n-1$ degrees of freedom. Figures with bands show either the 95% CI or the min–max over
  seeds; each caption says which.
- **What the intervals cover.** They measure simulation noise only. They say nothing about
  whether the parameters are right: every parameter is illustrative, not fitted.
- **Closed forms** (E3, E4) are evaluated exactly and carry no intervals.

## Reproduce

```bash
cd sim
pip install -r requirements.txt
python3 -m readpath_sim               # E1–E5, about 15 s on 8 cores
python3 -m readpath_sim e5 --seeds 20 # one experiment, more seeds
python3 -m unittest discover -s tests
```
